# 合约趋势策略研究(第一阶段结论: 海龟式不合格)

脚本: research/futures_backtest.py(引擎: 资金费+爆仓+杠杆+ATR风控)
research/futures_gates.py(三关检验)

## 引擎要点

- 永续合约模型: taker 0.05%, 资金费每 8 小时结算, 隔离保证金爆仓判定,
  净值含未实现盈亏;
- 海龟式趋势: 4h Donchian 120 根突破进场 / 60 根反向离场, 2xATR 止损,
  单笔风险 1%, 杠杆 2x, 双向。

## 三关结果(DOGE 五年, 修正引擎后)

| 检验 | 结果 |
|---|---|
| 基线 | **-15.24%**, DD -61%, 21 笔交易, **胜率 5%** |
| 突破周期 60/90/180 | -20.9% / -19.2% / -16.4%(胜率全在 4~5%) |
| 单笔风险 0.5%/2%/3% | -3.8% / +22.7% / +73.7%(风险越大收益越高但 DD 到 -80%, 且仅剩 1 笔交易) |
| 资金费 0 / 0.01% / 0.03%每8h | -15.2% / -28.5% / -54.1% |
| 滚动前推 | 固定 -8.5%, 每窗重选 -26.3%, 正窗仅 38% |
| 2026 六品种 | -3%~+9.4%, **全部跑赢买入持有**(持有 -15%~-42%) |

## 关键结论

1. **海龟式(慢突破+紧止损)在 DOGE 四年期上被震荡绞杀**: 2xATR 止损对
   DOGE 的波动太紧, 胜率只有 5% —— 进场即被甩下车;
2. 之前"趋势 +642%"的初步测试是 1h EMA 交叉 + 全仓 + 无 ATR 止损的
   特定组合, 正规风控(风险仓位+ATR止损+资金费)一加, 收益蒸发;
3. 资金费率是把双刃剑: 0.01%/8h 就吃掉 13 个百分点, 0.03%/8h 直接腰斩;
4. 唯一亮点: 2026 六品种趋势全部跑赢持有 —— 趋势基因"躲熊市"的价值真实存在,
   但"赚钱"还需要更好的设计(更快周期/宽止损/费率过滤), 那是下一轮研究。

## 决定

合约趋势"海龟式"版**未通过三关, 不上线**。现货网格仍是本仓库唯一通过
全部检验的策略。合约方向留作后续研究课题(见 research/ 目录)。
