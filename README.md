# 币安现货 DCA 网格机器人(Binance Spot DCA Grid Bot)

经过 **2021–2026 六年数据外样本检验**的朴素基线策略 + 纯实盘一体机(币安真实盘 / 官方测试网)。

- 图形界面: Tkinter 监控台 + 系统托盘, 24 小时无人值守
- 策略引擎: 4h EMA60 趋势过滤 + 跌 3% 加仓 + 涨 3% 均价止盈 + 固定止损
- 风控: 黑天鹅三路信号(闪崩/波动率/量能异动)暂停买入、断电恢复自检、STOP 刹车文件
- 智能推荐: 按账户余额自动分档 + BTC/ETH/BNB 选币

> ⚠️ 免责声明: 本项目仅供学习与研究, 不构成投资建议。真实交易有本金亏损风险, 过去回测业绩不代表未来表现。只投入你能承受全部损失的钱。

## 策略是什么(以及为什么这么朴素)

这是从几十个"聪明想法"里**被外样本检验淘汰剩下的唯一幸存者**:

| 组件 | 规则 |
|---|---|
| 入场 | 现价 > 4h EMA60 才买第一单(首单 = 每轮预算的 1/10) |
| 加仓 | 之后每跌 3% 追加一单, 最多 9 次(每轮共 10 单) |
| 止盈 | 价格回到均价上方 3% 全部卖出 |
| 止损 | 子弹耗尽且本轮总资产 < 每轮预算的 85% 时清仓离场 |
| 黑天鹅 | BTC 1h 跌超 3% / 波动率超基线 2.5 倍 / 量能超 3 倍 → 暂停买入 4 小时 |

**被五年外样本枪毙的特性**(每个都实测输给基线, 全部开源在研究目录里):
1h 多周期路由(ADX 闸门)、ATH 15% 动态止损、v3 逐轮止损、FNG 贪婪/恐惧闸门。

## 回测战绩(诚实版)

| 窗口 | 策略 | 买入持有 | 最大回撤 |
|---|---|---|---|
| 2021–2025 五年朴素回测 | +120.9% | +2360% | -33% (持有: -63%) |
| **2022–2025 滚动前推(更严格)** | **+14.3%(年化约3.4%)** | — | — |
| 2026-01 至今(6 品种同参) | -15.5%~-16.4% | -15.7%~-41.9% | -16%~-17% |

反过拟合三关检验(参数敏感性 / 滚动前推 / 多品种)完整结果见
`research/反过拟合三关检验结果.md`。**实盘预期请以滚动前推的年化约 3.4% 为锚**,
朴素回测的 17% 年化存在显著的回测溢价。

策略的基因是**用上行空间换回撤控制**: 牛市跑不赢持有, 熊市少亏很多。
研究脚本在 `research/` 目录, 可完整复现。

## 快速开始

### 1. 依赖

```bash
pip install ccxt pystray pillow
```

### 2. 建议先用币安官方测试网练手(假钱, 免费)

1. 打开 https://testnet.binance.vision → 用 GitHub 账号登录 → 生成测试网 API 密钥;
2. 把 `config_real.example.json` 复制为 `config_real.json`;
3. 填入测试网 Key/Secret, `testnet` 保持 `true`;
4. 运行:

```bash
python live_suite.py
```

软件会先做**真实挂单→立即撤单自检**(验证 API 现货交易权限, 不会成交),
然后断电恢复自检, 最后进入策略循环。

### 3. 真实盘

币安官网创建 API(只勾"现货交易", **绝不勾"提现"**, 建议 IP 白名单),
填入 `config_real.json`, `testnet` 改为 `false`。保存即自动启动。

## 界面按钮

| 按钮 | 作用 |
|---|---|
| API设置 | 密钥/币种/测试网; 保存即启动 |
| 智能推荐 | 自动读余额分档 + BTC/ETH/BNB 选币, 询问后一键开跑 |
| 启动·恢复 | 首次启动 / 暂停后恢复(自动校准挂单与持仓) |
| 暂停策略 | 只停决策: 不平仓、不撤单 |
| 一键平仓 | 终止策略 + 撤全部挂单 + 市价清仓 |

## 安全设计

- API 密钥只存本机 `config_real.json`(已加入 .gitignore, 不会进仓库)
- 余额分档: 每轮预算 = 余额 × 30%(50U 起, 500U 封顶), 余额 < 60U 拒绝实盘
- 黑天鹅检测: 市场自身信号(闪崩/波动率/量能), 无外部依赖
- `STOP_REAL.txt`: 程序目录放这个空文件, 60 秒内停止开新单
- 断电/崩溃恢复: 启动时撤残留挂单、以交易所真实持仓为准重建状态
