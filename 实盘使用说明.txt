============================================================
币安现货 DCA 实盘机器人 —— 使用说明(仅币安版)
============================================================
⚠️ 纯实盘软件: 保存币安 API 密钥后即真实下单(测试网除外)。
   策略来自历史回测, 不保证未来盈利。只投入你能承受全部损失的钱。

------------------------------------------------------------
模式说明: 真实盘 与 测试网(模拟盘)
------------------------------------------------------------
本软件只对接币安, 支持两种模式:

【测试网 = 币安官方模拟盘, 假钱练手, 强烈建议先用】
  注册网址(可复制): https://testnet.binance.vision
  方法: 浏览器打开上面网址 → 用 GitHub 账号登录(没有就注册一个)
        → 页面里找到 API 管理 → 生成测试网密钥(两件套, 假钱)
        → 在软件【API设置】里填入, 并勾选"这是币安测试网(Testnet)密钥"
  特点: 与真实币安同一套接口与行情, 但钱是假的, 随便练。

【真实盘 = 真金白银】
  方法: 登录币安官网 → 右上角头像 → 「API 管理」→ 「创建 API」
        权限只勾选: ☑ 允许现货及杠杆交易(Enable Spot Trading)
        其他全部不勾! 尤其是【启用提现】绝对不要勾!
        建议设置 IP 白名单。
  填软件时: 不要勾选"测试网"。

------------------------------------------------------------
智能推荐(已取消手工填预算)
------------------------------------------------------------
软件不再要求你手动填"每币预算"。点【智能推荐】后:
1. 自动读取你账户的 USDT 余额(测试网除外);
2. 余额 < 60U → 判定资金不足, 建议先测试网练手;
   余额充足 → 自动分档: 每轮预算 = 余额 x 30%(50U 起, 500U 封顶),
   每单 = 每轮预算的 1/10, 止损线 = 每轮预算 x 85%;
3. 选币: 【智能推荐】只考虑 BTC/ETH/BNB(永不主动推荐山寨);
   - 三者中已站上 4h EMA60 的 → 选离得最近的;
   - 都未站上 → 选距 EMA60 最近的, 机器人会等其站上后自动开仓;
   (手动下拉仍可选前10大市值白名单里的任意币种)
4. 弹出询问窗口: 点"是" → 按推荐配置直接开始运行;
   点"否" → 预选推荐币种, 你可在白名单里手动换币种后点保存。

稳定币种白名单(前10大市值, 已剔除稳定币与meme币):
BTC ETH BNB SOL XRP ADA LINK AVAX LTC DOT (均为 /USDT 现货)
注: 【智能推荐】只考虑 BTC/ETH/BNB, 永不主动推荐其他山寨。

------------------------------------------------------------
按钮说明
------------------------------------------------------------
[API设置]    填密钥/选币种/勾测试网; 保存后自动启动
[智能推荐]   在API设置窗口里: 自动读余额+选币+分档, 一键按推荐开跑
[启动·恢复]  首次启动或暂停后恢复; 恢复前自动校准挂单与现单
[暂停策略]   只停交易决策: 不平仓、不撤单, 持仓挂单原样保留
[一键平仓]   终极按钮: 终止策略 + 取消所有挂单 + 全部现单市价清仓
[最小化到托盘] 关闭窗口但策略继续; 托盘右键可打开/暂停/平仓/退出

------------------------------------------------------------
启动自检(每次启动自动执行, 日志以 [自检] 开头)
------------------------------------------------------------
1. 真实挂单→立即撤单一笔远低于市价的限价单, 验证 API 具备
   现货下单与撤单权限(该订单不会成交)
2. 断电恢复自检: 撤掉所有残留挂单 → 以交易所真实持仓为准
   核对本地状态 → 用成交记录重建本轮成本 → 失败进保守模式

------------------------------------------------------------
BNB 手续费抵扣(可选, 仅真实盘)
------------------------------------------------------------
API 设置窗口勾选后, 机器人会自动管理 BNB 抵扣:
  - 只有"账户几乎没有 BNB"(市值 < 0.5U)且 USDT 余额 >= 60U 时,
    才买入一次最小额(5U)的 BNB 用于抵扣手续费;
  - 账户已有 BNB 则绝不补买; 并开启抵扣(费率 0.1% -> 0.075%);
  - 每 24 小时最多检查一次; 只买不卖; 测试网自动跳过。

------------------------------------------------------------
黑天鹅检测(自动开启, 三路信号)
------------------------------------------------------------
每周期检测市场自身信号(对已发生冲击的快速反应, 不是预测):
  - BTC 1 小时跌超 3% (闪崩)
  - BTC 近 24h 波动率超过基线 2.5 倍 (波动骤升)
  - 成交量异动: BTC 或交易币种最后 1 小时成交量 > 前 24 小时
    均量的 3 倍 (大资金进场, 常比价格信号更早报警)
触发后: 暂停买入(开新仓+加仓) 4 小时; 止盈/止损照常执行。

------------------------------------------------------------
紧急刹车
------------------------------------------------------------
在程序文件夹里新建一个空文件 STOP_REAL.txt, 机器人下个周期
(60秒内)会保存状态并停止开新单。删除该文件后重启即可恢复。

------------------------------------------------------------
日常操作
------------------------------------------------------------
- 启动: 双击「实盘机器人.exe」或「实盘启动.bat」
- 看日志: 打开 程序目录旁 logs\live_trade_real.txt
- 每币种状态/成交: 程序文件夹里 live_state_*.json / live_trades_*.csv
- 重置某个币种: 删除对应 live_state_币种.json(注意先确认无持仓!)

------------------------------------------------------------
风险提示(务必读完)
------------------------------------------------------------
1. 网格/均值回归策略在单边暴跌中会浮亏加仓, 最大可亏光单币种预算
2. 市价单在极端行情下有滑点, 成交价可能明显偏离看到的报价
3. 机器人不保证 7x24 无故障; 断网/电脑休眠都会停摆,
   启动时请确认 Windows 睡眠设为"从不"
4. 只投入你能承受全部损失的钱
